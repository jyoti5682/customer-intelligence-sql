### Customer Intelligence & Revenue Analytics | MySQL

Built a SQL-based e-commerce analytics project using a simulated relational dataset covering customers, orders, products, payments, returns and inventory.

- Analyzed revenue, average order value, repeat customers, acquisition channels and product performance
- Used joins, aggregations, GROUP BY, HAVING, CASE, CTEs and window functions for business-focused analysis
- Investigated product profitability, returns, refunds, customer inactivity and purchase behaviour
- Added data-quality checks and documented the project in a GitHub-ready structure

**Tools:** MySQL, MariaDB, SQL, XAMPP, phpMyAdmin
